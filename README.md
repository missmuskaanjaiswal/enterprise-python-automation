# enterprise-python-automation
Py Project python environment checker for the Rab Tech  Academy Software Engineering Internship.Enterprise Python Automation Capstone Project

Overview

Enterprise Python Automation is a Python-based application designed to automate data collection, processing, scheduling, and report generation.

Features

- Backend API integration
- Automated data collection
- Data processing and validation
- Automated task scheduling
- PDF report generation
- Command-line interface (CLI)
- Error handling and logging
- Unit testing

Technologies Used

- Python
- FastAPI
- Requests
- JSON
- Pytest
- ReportLab

Project Structure

The project uses a modular structure to make the application easy to maintain, test, and extend.

Installation

Clone the repository:

git clone https://github.com/missmuskaanjaiswal/enterprise-python-automation.git

Install dependencies:

pip install -r requirements.txt

Usage

Run the application:

python -m enterprise_automation.main

Testing

Run automated tests:

pytest
